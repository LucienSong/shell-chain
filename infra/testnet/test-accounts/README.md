# Testnet Test Accounts

This directory stores the keystore files and address manifest for the 10 pre-allocated
testnet test accounts.

> **SECURITY**: Keystore files contain encrypted private keys. They are gitignored
> (`*.json` in this directory) to prevent accidental commits of key material.
> This `README.md` and `accounts-template.md` are the only committed files.

## Account Manifest

See `accounts.md` (generated by testnet setup, gitignored) for the current list of
addresses with their balances and key types.

## Regenerating Test Accounts

Run this on the testnet server (`/opt/shell/test-accounts/`):

```bash
cd /opt/shell
mkdir -p test-accounts

# Generate 10 Dilithium3 test accounts
for i in $(seq 1 10); do
    printf "test-password-account-$i" | shell-node --password-stdin key generate \
        --algorithm dilithium3 \
        --output ./test-accounts/account-$i.json
done

# Extract addresses
for i in $(seq 1 10); do
    addr=$(shell-node key inspect ./test-accounts/account-$i.json | grep 'Address:' | awk '{print $2}')
    echo "account-$i: $addr"
done
```

## Building Genesis Alloc

Use the `agents/genesis-builder` agent to generate the alloc block:

```bash
node agents/genesis-builder/genesis-builder.mjs \
    --keystores /opt/shell/test-accounts \
    --genesis   infra/testnet-genesis-template.json \
    --balance   1000000000000000000 \
    --output    infra/testnet-genesis.json
```

Or add accounts one-by-one:

```bash
shell-node genesis add-alloc \
    --genesis infra/testnet-genesis.json \
    --address 0x<account-address-64-hex> \
    --balance 1000000000000000000
```
